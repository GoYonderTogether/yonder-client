# @yonder/feature-meetings

聊天输入框上方的会议录音胶囊：开始、查看录制与保存时长、结束、本机历史、回放和云端处理结果。没有独立页面、路由或模态窗口。

录音与文件由原生 `meeting-recorder` 插件持有；应用注入状态和控制函数。胶囊是与手机 Dock 分离的浮层，展开只改变自身，不撑高输入框或推动聊天布局。再次点按收起，结束按钮始终可用。收起、切页面不停止录音，切换账号通过会话清理结束旧采集。聊天短语音只互斥启动麦克风，保持独立生命周期。

M2 在录音结束后展示实际上传、批量转写、纪要和 Bot 回传状态；展开显示最新几句转写和完整文字入口。未知付费请求必须确认后才重试；已保存原音频不删除。Bot 消息中的真实会议引用会展开同一个胶囊。

桌面原生持久上传先完成 macOS 纵向验收；iOS/Android 仍保留 M1 后台录制与中断保存，不宣称已有后台上传。Web 和手机可查看已有云端结果。录制中补转写留 M3，完整系统灵动岛/Live Activity 留 M4；胶囊不是系统 Live Activity。当前不提供暂停、续录或语音通话。
