# 微信小程序实现与验收

## 目标与授权

2026-11-15：用户选择 Taro，要求在现有客户端基础上新增纯手机微信小程序。先跑通真实登录、聊天、图片上传，再覆盖现有大部分可用功能；保留 Yonder 风格，适配胶囊、安全区、键盘、微信返回与分享。允许安装开发工具、依赖与本机验证环境，允许并行子 Agent。此次不包含生产发布或小程序审核提交。

现有 Web/Tauri 与服务端任务正在 main 并行修改。小程序新增在公开客户端 `apps/miniprogram`，不迁移或重写现有端，不回退他人修改。服务端、模型密钥、数据库与上传凭证留在私有环境。

## 复用边界

- 复用 `packages/protocol` 与 `packages/api-client` 的端点、错误和刷新语义；共享传输必须保持原端兼容。
- 不整包移植依赖 React 19、浏览器 DOM 和 IndexedDB 的 `ui-data`、`ui-shell`。
- 小程序入口使用所选 Taro 官方支持的 React 版本，现有 Web 版本保持不变。
- 复用品牌、已有文案与设计值；控件、导航、键盘和滚动按小程序宿主实现。
- 登录及聊天的稳定展示结构、样式和纯状态规则应由 Web/iOS/Android 与 Taro 实际共用；宿主事件、DOM、IndexedDB、文件选择/预览与导航分别适配。不能仅复用 tokens 后独立重写页面并称为同源组件。
- 以当前服务端真实能力决定功能，不创造示例用户、消息、模型、记忆或任务数据。
- 本机文件夹连接器等原生桌面能力不在小程序伪装为可执行；可按已有服务端权限查看、管理已连接设备。

## 关键行为

1. 返回用户启动时恢复会话；小程序默认微信登录，首次通过手机号授权关联或注册，已绑定账号不重复索取手机号；保留验证码/密码辅助登录。头像与昵称由用户主动选择，既有账号资料不覆盖。
2. 会话与消息读取真实接口；发送使用 clientNonce 幂等语义，失败保留可重试内容，不重复上传/发送。
3. 实时事件沿用已有协议。进入后台不承诺常驻连接；回前台恢复认证、重连并补拉当前数据，云端 Agent 继续执行。
4. 图片通过微信文件选择与上传，保持现有附件鉴权和消息关联；可查看图片与实际附件结果。
5. 退出或切换账号清理 token、账号缓存及草稿的归属，不串号。
6. 页面处理胶囊、安全区、键盘、返回、中文英文、加载/空/错误状态；只呈现已接通的动作。

## 聊天页同源适配契约

本节是 2026-11-16 聊天页与图片上传复刻的行为要求；完成状态与截图另记仓库外验收资料。

- 连续发送者分组、消息气泡、附件、上传缩略图和输入区使用两个宿主实际消费的共享展示组件与样式；正文沿用既有 Markdown 解析能力与安全内容规则，不额外编写解析器。
- message 按 id/clientNonce/version 合并，旧版本不覆盖新正文，消息确认不丢已有 run。生成中、停止、重试和重连状态以真实 API/事件及服务端快照为依据；不能为没有版本的 run 事件编造时序保证。
- 普通聊天的当前步骤正文实时显示；若该步骤最终转为工具调用，按服务端更新撤回临时正文，再显示最终回复。客户端接受正文增量及清空，不重复追加最终整段；不把推理内容或工具参数当作正文展示。会议、摘要和子任务的输出契约独立保持。
- 发送失败保留一份可重试内容，上传移除/取消不再关联到后续消息；旧会话/账号的异步回调不能写入新会话。附件总数和大小对齐当前 Web 的 10 件、每件 20 MiB，微信单次选择按平台能力分批完成。
- 图片选择、缩略图、上传中/失败重试、发送、授权下载、预览与返回形成闭环；仅图片可发送，附件不可转为公开 URL。微信临时路径不承诺与 Web IndexedDB 等同的跨重启持久性。
- 只有用户在底部时跟随流式输出；上翻阅读和加载更早消息维持锚点，回到最新入口恢复跟随。键盘与可见高度由一个宿主机制管理，避免自动抬升和手动偏移重复；发送/停止按钮保持可达，监听随页面卸载。
- 沿用原有交互与动效 tokens，尊重减少动态效果。分别记录源码构建、合成状态、真实模型/图片链路与实际宿主证据；H5、几何模拟和隔离 WebView 不能替代微信宿主键盘、胶囊和权限验证。
- 群聊与私聊在顶栏胶囊左侧用「⋯」打开会话资料或设置。群资料、添加成员与群 Bot 设置使用 `Page` 和 Taro 页面栈，左上角返回。群主在群资料底部解散群聊。选人复用 `chat-model` 的联系人筛选和最近私聊排序。
- 真人私聊和群聊的顶栏左对齐显示名称。Bot 私聊复用 `chat-model` 的会话分类和运行状态，在聊天区上方单独居中显示头像。头像下方的单行文字空闲显示名字，工作时显示状态，超长用省略号。只有双方参与时省去消息头像。群资料使用组合头像，自己的 Bot 从身份卡进入资料编辑页。
