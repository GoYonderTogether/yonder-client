# 云端技能

2026-11-16。行为依据是 Yonder 笔记中的“架构-10 能力与连接”，服务端实现位于独立的私有仓库；这里仅包含公共协议、API 客户端和界面。

## 用户路径

1. 打开“我 → 技能”（`/me/skills`），查看平台与自己导入的技能，开关决定 Bot 能否使用。
2. 导入一个包含 `SKILL.md` 的文件夹，或选择多个文本文件。预览文件清单后提交；自己的技能可以完整替换文件包或删除，平台内容不能覆盖或删除。
3. 打开详情，按需查看 `SKILL.md` 和参考文件。读取是显示文本，不执行脚本或 HTML。
4. 普通聊天没有额外技能栏。行首或空白后输入 `/` 查看命令和技能，输入 `@` 查看联系人或 Bot。继续输入可筛选，方向键可浏览或翻页，Enter、Tab 和点击都能确认当前候选。Shift+Enter 换行。没有可确认的候选时，桌面端 Enter 发送，手机端 Enter 换行并通过发送按钮提交。中文输入法组合期间保留原生选字。
5. 只有确认候选后才绑定本次输入的技能 ID；删除标记按实际编辑位置清除对应绑定，同名技能不以字符串猜身份。草稿按账号和会话隔离，发送失败重试保留原选择；未能唯一定位的程序化编辑保留文字并解除歧义绑定。没有明确选择时仍由模型按现有技能索引自行判断。
6. 正式命令包含 `/compact`，明确选择后压缩当前会话的模型上下文，保留其余草稿和可见聊天记录；普通未确认命令不执行。不提供演示性的 `/skills`，技能管理仍从“我 → 技能”进入。`@` 补全称呼并在草稿保留成员身份，不另发通知或改变消息的聊天目标。
7. 浮层在桌面和手机都有高度上限，大量候选只在列表内滚动；键盘弹出时以可见视口限制高度。未激活候选的描述一行省略，激活后最多四行，短描述不补空行。英文技术名称旁显示灰色中文名称，并支持中文筛选。
8. 正在补全的 `@` 或 `/` 词段，以及已确认的提及和技能，都在输入框内蓝色高亮。浮层标题只显示候选类别。标记可以退格、删除、撤销和重做，文字与真实 ID 绑定同步变化。保留原生文本选区、粘贴、中文组合输入和滚动，不增加编辑器依赖或常驻已选栏。选择状态不冒充服务端已加载状态。

## 正式内置

内置内容是云端平台技能，使用相同的版本、启停和读取接口。会议后续事项仅用于上一轮链路验收，不作为默认内置内容；用户自己的同名技能不受影响。

`skill-creator`（技能创建助手）基于固定版本的 OpenAI Codex 上游方法适配，来源和许可证保留在私有技能包中。创建和修改使用 Yonder 自己的云端用户技能存取，不依赖不可用的本机 Python、Shell 或 `$CODEX_HOME`。内置技能提供中文名；新建技能也应带 `metadata.display-name-zh`，旧导入包缺少时兼容显示原信息，不伪造翻译。

AI 写入后，客户端在运行完成、失败或取消时刷新技能查询；最终回复失败不等于此前写入未发生。新技能可以进入后续补全候选，保存事实仍以服务端返回的 ID 和版本为准。

## 包的分工

- `packages/protocol/src/skills`：纯公共形状；工具消息在 `src/agent`，不含数据库或供应商代码。
- `packages/api-client`：`/v1/skills` 管理和文件读取接口。
- `packages/ui/data/src/hooks/skills.ts`：查询、变更和缓存失效；登出沿统一账号清理。
- `packages/ui/features/me/src/skills`：导入、列表和详情。
- `apps/web/src/app/completion`：`/`、`@` 共用的词段识别、候选筛选、浮层和键盘操作；不另建引用后台。草稿模块保存明确确认的标记和技能身份，消息仍走 `skillIds`。

## 当前边界

包最多 32 个 UTF-8 文本文件，单文件 128 KiB、合计 512 KiB。目录导入保留包内相对路径，二进制或非法编码明确拒绝，不能以部分导入成功替代整个包。只有根 `SKILL.md` 和附属文本的内容进入云端包；凭据属于连接器或执行端配置。

技能加载没有外部执行权限。设备技能、任意 MCP 连接、二进制资源与脚本执行需要服务端对应能力接通；本客户端不伪装已提供。
